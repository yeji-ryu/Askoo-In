# Askoo In 📱  
_A real-time, anonymous Q&A mobile application_

## 📖 Project Overview
This project was developed as part of the **Object-Oriented Programming (Java)** course.  
The goal was to design and present an application or game, and I created **Askoo In**, a **real-time Q&A app** for classrooms.  

The name **Askoo In** comes from:  
- **Ask In** → meaning “ask questions inside your phone”  
- **Prof. Koo** → our professor’s name  
- Combined as **Askoo In** ✨  

---

## ❓ Problem
We observed a common issue in many classes:  
Students often **hesitate to ask questions or provide answers** for various reasons (shyness, peer pressure, etc.).  

---

## 💡 Our Solution
To address this, we designed **a chat-based, real-time, anonymous Q&A platform** where:  
- Students can freely ask questions **without revealing their identity**  
- Professors receive questions and answers **instantly via Firebase integration**  
- The app encourages **active participation** in lectures  

---

## 🔐 Key Features
From the planning phase, we focused on **usability** and **security**:
- ✅ **Real-time communication** with Firebase  
- ✅ **Anonymous participation** using hash functions  
- ✅ **Confidentiality** ensured by AES encryption  
- ✅ **Filtering system** to block inappropriate content  
- ✅ **Secure coding practices** (tested & patched via self-conducted security checks)
